# Session retrospective

## Outcome and evidence

What was requested, what changed, and which checks or observations support it?

## Learning and impact

What affected correctness or effort? Would it recur, and would an existing
instruction or check already prevent it?

## Proposed Harness changes

For each justified proposal, name the owning file and the concrete text or
behavior to change. State the expected improvement and how to verify it.
If none qualify, write "No harness changes proposed."

## Review boundary

Does a proposal affect data, tool authority, host compatibility or external
systems? State any unresolved product decision and whether applying it is
authorized.
