# keystone

Keystone is the selected product name for delta-aware CI orchestration for
Bazel monorepos. This checkout is currently a seed repository with no Go
module, Bazel targets or runtime implementation. The planned roadmap covers a
Go control plane, queued jobs, ephemeral runners, hybrid target selection,
daemonless OCI assembly, caching, BEP telemetry and quality gates.
